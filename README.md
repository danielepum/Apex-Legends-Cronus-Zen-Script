🧩 **Troubleshooting**

**Script Not Triggering**
- Verify the correct Zen slot is selected via the LED display
- Confirm the script compiled successfully in Zen Studio — a compile error will prevent activation
- Reconnect your controller and restart Zen Studio
- Update Cronus Zen firmware if the issue persists after reconnection

**Recoil Control Feels Incorrect**
- Lower or raise recoil strength gradually — large value jumps make it harder to find the right point
- Double-check your in-game sensitivity values match the script's expected range
- Test in the firing range with a single weapon before testing across multiple weapons

**Aim Enhancement Feels Off**
- Start with anti-recoil values before adjusting aim behavior — the two systems interact
- Confirm your ADS sensitivity matches your look sensitivity in Apex settings
- Lower aim responsiveness values if tracking feels too aggressive

**Input Delay or Lag**
- Use a stable, shorter USB cable and connect directly to the console
- Avoid USB hubs or extenders between the device and console
- Restart your Cronus Zen device and relaunch Zen Studio

**Settings Not Saving**
- Reprogram the script to the device after making changes in Zen Studio
- Confirm Zen Studio completed the upload successfully before disconnecting

**Behavior Changes After a Patch**
- Respawn patches weapon recoil and movement mechanics regularly
- Check the changelog for updates after major patches
- Retune in the firing range before returning to ranked play
